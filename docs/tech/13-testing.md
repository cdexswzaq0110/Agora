# 13 · 測試策略

```bash
cargo test --workspace
```

離線執行，不呼叫任何 CLI，不花額度。目前 156 個測試通過（v0.6），另有 1 個需要網路的探測測試預設略過。前端另用 `node scripts/check-web.mjs` 檢查 module 語法、具名 import 與離線快取清單。

## 原則（來自 Agent Kernel 的 core rules）

- **測要保證的行為，不測實作它的小函式**（Agent Kernel lessons/0005）。例如「審查通過但沒有驗證指令，就不能是已確認」是端到端測試，不是去測某個解析函式。
- **外部 CLI 的格式以實測為準**：解析器寫成純函式，用錄下來的真實格式當測試資料（lessons/0001、0002、0003）。
- **防護一定有測試**：計費防護、額度保護、發言上限、信任模型、路徑穿越，每一個都有。

模擬提供者（`provider/mock.rs`）是確定性的，並支援幾個測試用標記：

| 標記 | 效果 |
|---|---|
| `[mock:fail]` | 這則發言失敗 |
| `[mock:slow]` | 變慢，用來測試取消 |
| `[mock:split]` | GPT 裁判判另一方勝，用來測試裁判意見分歧 |
| `[mock:write]` | 執行者真的寫一個檔案，用來測試 worktree |
| `[mock:echo-headers]` | 把看到的逐字稿標題回傳出來，用來測試盲審 |
| `[mock:thin]` | 團隊階段的角色小節只有標題沒有內容，用來測試「缺漏」 |
| `【團隊階段】`（提示詞裡） | 依這次被指派的角色逐一寫小節，並依階段補上待你回答的問題、建議、任務、保留的異議（不是測試標記，是團隊提示詞本身的標記） |

## 手動測試建議

```bash
cargo run -p agora-server -- --demo --port 4799 --data <暫存資料夾>
```

`--data` 指到暫存資料夾，就不會動到真正的 `%APPDATA%\Agora`。示範模式會多出兩個模擬模型，可以在不花任何額度的情況下走完所有流程。
