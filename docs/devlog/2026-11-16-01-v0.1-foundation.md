## 起點

使用者的手寫筆記（最低標準）：

1. 一個網頁、一個桌面 exe（參考自己的 GitHub 作品，其中一個能接手機）。
2. **核心**：打造專案時，能自由選擇單一 GPT、單一 Claude，或讓兩者一起協做、討論、辯論的平台；它本身是一個 agent。
3. 一個可以顯示 GPT、Claude 剩餘用量的圖示。
4. 參考目前的 Agent 資料夾和市面上熱門的 GitHub skill（記憶體壓縮、驗證流程等）。
5. App 與網頁的版型、配色參考 github.io 網站。
6. 從這個專案開始協做打造。

## 開工前的實測（決定設計的關鍵證據）

- `codex app-server` → `account/rateLimits/read`：Plus 方案，5 小時窗 0%、每週窗 32%。結論：Codex 的額度可以**免費**查。【已確認】
- 從 `claude.exe` 2.1.252 的字串裡找到 `rate_limit_event` 的 schema（`unifiedWindows.five_hour/seven_day.utilization`）。結論：Claude 的額度只能在執行時順便取得。【已確認 schema；實際送出的事件仍是未驗證，因為 Claude CLI 登入已過期】
- `claude -p` 在登入過期時回傳 `subtype: success` 搭配 `is_error: true` → [lessons/0001](../lessons/0001-claude-is-error-hides-in-success-subtype.md)。
- `codex exec` 用 config.toml 的預設模型 `gpt-6.1-sol` → 回傳 `model_not_found` → [lessons/0002](../lessons/0002-codex-configured-model-not-on-plan.md)。

## 實作

- `agora-core`：提供者（Claude／Codex／Mock）、四種模式（單人、協做、討論、辯論）、用量、記憶壓縮、驗證、儲存。
- `agora-server`：REST 與 SSE、信任模型（本機信任、手機配對、同源檢查、CSP）、內嵌網頁。
- `web/`：原生 JS、github.io 風格、深淺色主題、PWA、用量小工具。
- `src-tauri/`：視窗、系統匣、置頂小工具、原生通知、關窗縮到系統匣。
