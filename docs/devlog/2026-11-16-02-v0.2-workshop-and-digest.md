# 2026-11-16 · v0.2 先討論再實作＋每日技術情報

## 起點

使用者原話：

> 請你更多發想後全部實作。我的核心是希望**協作討論後給出更好的方案，再去實作**。
> 新增一個功能：每天都要爬蟲搜尋國外論壇或 GitHub 熱門的專案，整理成摘要給我閱讀……不是全部下載下來，而是整理資料。
> 開發這個專案請你要有完整的開發日誌以及技術文件，提供我理解及日後講說這個專案。

## 決策

| 決策 | 理由 | 文件 |
|---|---|---|
| 新增第五種模式「方案工作坊」，並設為預設 | 直接對應核心需求：先把方案討論好，再實作 | [ADR 0003](../adr/0003-workshop-approval-gate.md) |
| 核准關卡預設要人決定，可以修改方案、要求修訂（最多 2 次）或只保留方案 | 「更好的方案」最終要由使用者判斷；HumanGate 的精神 | ADR 0003 |
| 寫入一律在 git worktree 進行，不在 worktree 裡 commit | 使用者的工作目錄在套用前不會被動到；不觸發專案的 hooks | [ADR 0004](../adr/0004-worktree-without-commits.md) |
| 情報只抓**列表頁**（標題、熱度、簡介），由一次 CLI 呼叫整理 | 符合「不要全部下載」；成本可預期 | [技術文件 05](../tech/05-daily-digest.md) |
| Reddit 列為盡力而為的來源 | 匿名存取時好時壞（403／429） | [lessons/0006](../lessons/0006-reddit-anonymous-access-is-best-effort.md) |
| 預設隔離 CLI 的個人設定 | 實測中，Codex 在 Agora 的議題裡用了使用者個人的 MCP 工具 | [lessons/0007](../lessons/0007-cli-personal-config-leaks-into-agent-runs.md) |
| 第三家模型（Gemini 等）**不做** | 這台電腦沒有安裝；ADR 0001 要求計費來源能被程式確認 | 本頁「被擋住」 |

## 證據

- `cargo test --workspace`：88 個測試通過，另有 1 個需要網路的探測測試預設略過。v0.1 時是 50 個。【已確認】
- **從介面完整走過一次工作坊**（模擬提供者，示範模式）：提案 ×2 → 互評 ×2 → 整合 → 紅隊 → 修訂 → 停在核准關卡 → 在介面編輯方案後核准 → 在 worktree 實作 → 驗證 ×2 通過 → 依驗收標準審查通過 → 「已確認」 → 查看 diff → 套用 → demo repo 出現暫存（staged）的變更，worktree 與分支都已移除。【已確認，瀏覽器面板】
- **真的 Codex 在 worktree 裡寫程式**：`src/lib.rs` 新增 12 行（`multiply` 加單元測試），`findstr` 驗證通過。這次實作輸入 594,389 tokens（其中快取 559,872）、輸出 6,188；5 小時窗從 4% 升到 12%。【已確認】
- **真的每日情報**：抓到 HN 29、GitHub 12、Lobsters 25、dev.to 20、HF 25 則，Reddit 0（403）；排序後保留 36 則；Codex `gpt-5.6-sol` 約 60 秒整理完，輸入 27,484（快取 15,616）、輸出 2,890 tokens；摘要裡有 74 個 `[n]` 引用連結。【已確認】
- **隔離個人設定的旗標有效**：Claude 的 init 事件裡 `mcp_servers: []`、外掛 0 個、沒有 hook 事件；Codex 加上 `--ignore-user-config` 後正常回覆，輸入 tokens 從 24,926 降到 20,643。【已確認】
- MCP server：`initialize`、`tools/list`（4 個工具）、Agora 沒開時回傳 `isError` 而不是當掉。【已確認，`mcp_server_handshake_and_tool_list`】

## 坑

- [0005](../lessons/0005-raf-does-not-fire-in-hidden-pages.md)：頁面在背景時 `requestAnimationFrame` 不會觸發，議題頁就停在舊狀態。
- [0006](../lessons/0006-reddit-anonymous-access-is-best-effort.md)：Reddit 對 reqwest 回 403，對同樣 User-Agent 的 curl 卻回 200，之後兩者都變成 429。
- [0007](../lessons/0007-cli-personal-config-leaks-into-agent-runs.md)：由 Agora 驅動的 Codex 載入了使用者個人的 MCP 工具（`js / cua_repl`）。

## 成本觀察（給使用者的提醒）

- 討論類的發言（提案、評論、總結）每則約 1 千到 3 萬 tokens。
- **實作類的發言**會跑完整的 agent 迴圈（讀檔、執行指令、改檔），一次可能用到**數十萬 tokens**，其中大部分是快取。在 Plus 方案大約占 5 小時窗的 8%。
- 所以工作坊在**核准之前**都很便宜，核准之後才是主要成本。這正是核准關卡存在的另一個理由。

## 被擋住／還沒驗證

- ⛔ **第三家模型**：這台電腦沒有 `gemini`、`qwen`、`opencode` CLI。ADR 0001 規定，必須能用程式確認計費來源是訂閱才能接入。等 CLI 安裝後，依 [技術文件 03](../tech/03-providers-and-billing-guard.md#新增一個提供者) 的步驟加入。
- 【未驗證】Claude 的實機執行（登入已過期）、真實手機的區網／Tailscale 配對與 QR code（開啟區網會跳出 Windows 防火牆對話框，所以沒有在測試中開啟）、系統匣「今日技術情報」選單的點擊、NSIS 安裝檔。
